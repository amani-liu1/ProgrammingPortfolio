# [NovaMath]

## Overview
This Processing code creates a functional interactive calculator with custom visual buttons for numbers and math symbols. It allows users to perform basic operations like addition, subtraction, multiplication, and division, as well as calculate squares and square roots. The program dynamically tracks user clicks, updates the screen in real time, and logs calculation steps in the console.
